## One application, a complete delivery journey

![Source, build, test, secure, release, and observe](docs/visuals/az400-cover.svg)

Start with traceable work and source control. Build and test immutable artifacts,
design protected releases, diagnose failures, and prove recovery and cleanup.
The two capstones bring those skills together in GitHub and Azure DevOps.

| Course area | Labs | What you practise |
|---|---|---|
| Processes and communication | 01–03 | Work flow, metrics, and documentation |
| Source control | 04–06 | Policies, repository management, and recovery |
| Build and release | 07–19 | Packages, CI, testing, delivery, and infrastructure |
| Security and compliance | 20–23 | Identity, federation, secrets, and scanning |
| Instrumentation | 24–25 | Alerts, telemetry, traces, and analysis |
| Foundation and capstones | 00, 26–27 | Readiness and end-to-end delivery |
